================================================================================
                        ONLINE LEARNING LOOP
================================================================================

for each batch in test_loader:
    (recent_batch, current_batch) = batch
    ↓
    
┌─────────────────────────────────────────────────────────────────────┐
│ RECENT BATCH UPDATE (Learn patterns from history)                   │
│                                                                     │
│  model.train()                                                      │
│  freeze_adapter(True)    # Fix concept drift detection             │
│  freeze_bias(False)      # Update backbone bias                    │
│  _update_online(recent_batch)                                      │
│    └─ Forward pass: recent_batch → concept_drift                   │
│    └─ Update: backbone weights & bias                              │
│  freeze_bias(True)       # Fix bias after update                   │
│  recent_batch ← accumulate for next iteration                      │
└─────────────────────────────────────────────────────────────────────┘
    ↓
    
┌─────────────────────────────────────────────────────────────────────┐
│ CURRENT BATCH PREDICTION (Detect drift & evaluate)                 │
│                                                                     │
│  model.eval()                                                       │
│  with no_grad():                                                    │
│    outputs = forward(current_batch)                                │
│    ├─ Generate new concepts from current_batch                     │
│    ├─ Compute drift (concept_current - concept_recent)             │
│    ├─ Generate adaptations via Adaptation Generator                │
│    ├─ Apply Down-Up adapters to backbone                           │
│    └─ Return predictions                                           │
│                                                                     │
│  metrics = evaluate(outputs, labels)                               │
│  MSE ← record for averaging                                        │
│  MAE ← record for averaging                                        │
└─────────────────────────────────────────────────────────────────────┘
    ↓
    [REPEAT for next batch]
    ↓
Result: MSE, MAE aggregated over all test samples


================================================================================
                        DOWN-UP ADAPTER APPLICATION
================================================================================

Applied to each Linear, Conv1d, LayerNorm layer:

Original layer computation:
    y = W @ x + b

With Down-Up adaptation:
    y' = (W * scale_out) @ (x * scale_in) + (b + bias_shift)
    
Where:
    scale_in = 1 + adaptation[..., 0:in_features]
    scale_out = 1 + adaptation[..., in_features:2*in_features]
    bias_shift = adaptation[..., 2*in_features:]
    
Result:
    - Efficient (minimal overhead)
    - Learnable per-layer (bottleneck maps drift → scales)
    - Bounded (clipping ensures stability)

================================================================================
                        KEY EQUATIONS
================================================================================

1. CONCEPT EXTRACTION
   concept_t = mean(MLP1(x_t))
   concept_recent = mean(MLP2(recent_batch))

2. DRIFT COMPUTATION
   drift = concept_t - concept_recent
   [Optional: drift ← α * drift_prev + (1-α) * drift  if ema > 0]

3. ADAPTATION GENERATION
   adaptation = clip(Generator(drift), max_norm=1.0)
   
4. DOWN-UP SCALING
   y_adapted = (W * (1 + scale_out)) @ (x * (1 + scale_in)) 
               + (b + shift)

5. LOSS (Online)
   L = MSE(y_pred, y_true) + [optional regularization]
